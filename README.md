📅 Cronograma

Um calendário interativo para organizar, visualizar e compartilhar escalas de trabalho e dias de folga de forma simples e intuitiva.

✨ Sobre o projeto

O Cronograma foi desenvolvido para facilitar o planejamento da rotina de trabalho, permitindo visualizar os dias de trabalho e descanso ao longo do ano, personalizar escalas e compartilhar cronogramas com outras pessoas ou entre seus dispositivos.

A aplicação possui uma interface responsiva, opções de personalização visual e recursos para adaptar o calendário à rotina de cada usuário.

🚀 Funcionalidades
📆 Calendário anual: visualize os dias de janeiro a dezembro e navegue entre diferentes anos.
🔄 Diferentes tipos de escala: escolha entre os modelos 12x36, 5x2 ou configure uma escala personalizada.
⚙️ Configuração personalizada: informe seu nome, defina uma data de referência e indique se nesse dia estava trabalhando ou de folga.
✏️ Edição de dias: altere o status de uma data específica e adicione comentários.
🔁 Restauração automática: retorne ao padrão calculado da escala quando necessário.
🌴 Planejamento de férias: cadastre períodos de férias com data de início e quantidade de dias.
🌙 Tema claro e escuro: escolha a aparência mais confortável para você.
🔗 Compartilhamento de cronogramas: compartilhe sua escala com outras pessoas e permita a visualização de cronogramas compartilhados.
🆔 Identificação por ID: utilize o recurso de identificação para recuperar um cronograma existente.

🛠️ Tecnologias utilizadas
HTML5 — estrutura da aplicação.
CSS3 — estilização, layout e personalização visual.
JavaScript — lógica do calendário, configurações e interações.
Firebase — integração utilizada pelo projeto para recursos relacionados a dados e compartilhamento.

📱 Acesso pelo celular

A aplicação pode ser acessada pelo navegador do celular quando publicada em uma hospedagem web compatível.

Para desenvolvimento local, o acesso por outro dispositivo depende da configuração da rede e das permissões de firewall. Uma hospedagem pública permite acessar o projeto por um link, sem depender do IP local do computador.

🎯 Objetivo

Este projeto tem como objetivo tornar o acompanhamento das escalas de trabalho mais prático, reunindo calendário, personalização e compartilhamento em uma única aplicação.
